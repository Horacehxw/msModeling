项目已延期 2 天（原定 3.23 交付）。**Qwen3 指标大幅改善**：重新采集的 Prefill profiling 数据使 M3 从 15.4% 跃升至 61.5%（超 Phase 2 目标 >50%），M5 达 89.0%（超 Phase 3 目标 >80%）。**DSv3 仍是核心瓶颈**：DispatchFFNCombine 占 DSv3 43-46% 真实耗时但 shape 不匹配，导致 M6 仅 0.106-0.239。

## 二-A、验证命令与数据源

```bash
DATA_DIR=tensor_cast/performance_model/perf_database/data/ATLAS_800_A3_752T_128G_DIE/vllm_ascend/vllm0.18.0_torch2.9.0_cann8.5
PROF=/Users/horacehxw/Data/Profiling/Profiling-0325-final-vllm-new

# Qwen3 Prefill: dominant M=4112 (MatMulV2 99%), FlashCommV1=ON
python3.10 -m tensor_cast.scripts.text_generate Qwen/Qwen3-32B \
  --num-queries 1 --query-length 4112 --word-embedding-tp row \
  --device ATLAS_800_A3_752T_128G_DIE --world-size 16 --tp-size 16 \
  --quantize-linear-action DISABLED --performance-model profiling --compile \
  --perf-database "$DATA_DIR" --enable-flashcomm-v1 \
  --export-metrics results/qwen3_prefill_metrics.json
  → TC M-dim: 4112 | Profiling M-dim: 4112 ✅ 匹配

# Qwen3 Decode: dominant M=16 (cudagraph padded)
python3.10 -m tensor_cast.scripts.text_generate Qwen/Qwen3-32B \
  --num-queries 16 --query-length 1 --context-length 4096 --word-embedding-tp row \
  --device ATLAS_800_A3_752T_128G_DIE --world-size 16 --tp-size 16 \
  --quantize-linear-action DISABLED --performance-model profiling --compile \
  --perf-database "$DATA_DIR" \
  --export-metrics results/qwen3_decode_metrics.json
  → TC M-dim: 16 | Profiling M-dim: 16 ✅ 匹配
```

## 八、数据版本切换建议

**建议切换到 vllm 0.18.0 profiling 数据**, 理由:
1. Qwen3 M3 从 31.2%(Phase1) → **61.5%**(v0.18.0), 首次超过 50% 目标
2. DSv3 MLA prefill 从 RINGMLAPrefillBF16Kernel(无 CSV) → FIA(有 CSV), 可匹配
3. 同 CANN 8.5, kernel 行为不变
4. vllm 0.18.0 是生产目标版本
5. 唯一 caveat: Qwen3 PF 使用 FlashCommV1 (reduceScatter+allGather), DC 使用 allReduce — TC 参数需对应
