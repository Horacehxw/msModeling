### 2.5 MISS 根因分析 (按优先级)

**Qwen3 (7-8 个 non-ZC MISS ops)**:
| 算子 | 延迟(ms) | 根因 | 修复路径 |
|:-----|--------:|:-----|:---------|
| `tensor_cast.attention` | 1.491 | FIA CSV 格式不匹配 | FIA microbench CSV + Scheme A 查询 |
| `aten.mul.Tensor` | 0.798 | elementwise shape mismatch | 扩展 elementwise 匹配规则 |
| `tensor_cast.apply_rope` | 0.121 | shape mismatch | RoPE CSV dtype gap (R13) |
| `aten.copy_.default` | 0.062 | 无 CSV | 添加 TensorMove CSV |
| `tensor_cast.reshape_and_cache` | 0.042 | shape mismatch | Cache op CSV 采集 |
| `aten.add.Tensor` | 0.077 | elementwise shape mismatch | 同 mul |
| `aten.index.Tensor` | 0.042 | 无 CSV | Index op 数据采集 |

**DSv3 (25-27 个 non-ZC MISS ops, 关键项)**:
| 算子 | 延迟(ms) | 根因 | 修复路径 |
|:-----|--------:|:-----|:---------|
| `tensor_cast.all_to_all` | 0.226 | 通信数据缺失 | all_to_all microbench (HDY) |
| `tensor_cast.multihead_latent_attention` | 0.218 | MLA shape mismatch | MLA composite + FIA CSV |
| `tensor_cast.mlapo_quant` | 0.165 | shape mismatch | MLA quant CSV 采集 |
| `tensor_cast.add_rms_norm2` | 0.113 | CSV 未找到 | AddRmsNorm CSV 命名问题 |
| `tensor_cast.add_rms_norm_quant2` | 0.099 | CSV 未找到 | 同上 |
| `aten.mul.Tensor` (MoE) | 0.085 | shape mismatch | MoE 路由小算子 |
| `tensor_cast.unpermute_tokens` | 0.058 | CSV 未找到 | MoE token op 数据 |
| `tensor_cast.permute_tokens` | 0.033 | CSV 未找到 | 同上 |
| `tensor_cast.swiglu` (PF) | 0.003 | input_count_mismatch | SwiGlu 输入数匹配 (bug) |

> **DFC (DispatchFFNCombine) 不在 MISS 列表中** —— 因为 DFC 融合 pass 未实现，TC 仍将其分解为子算子。真实 NPU 上 DFC 占 40-42% 延迟，这是 DSv3 M3/M5 低的根本原因。
