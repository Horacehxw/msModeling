## 四、Qwen3 DC 回退根因分析

### 4.1 现象

- **Baseline (pre-merge)**: 63 ops total -> 56 hit, 7 miss -> M3=57.1%
- **Merge**: 56 ops total -> 48 hit, 8 miss -> M3=38.5%
- 净减少 7 个 ops; 同时 8 个原 HIT 的变为 MISS 或消失

### 4.2 根因: develop plugin 架构改变了 op graph

develop 重构了模型转换流程:
- **之前**: `TransformerModel` 内联 `patch_attention`, `patch_moe`, `shard_model` 等方法
- **之后**: 独立函数在 `transformations.py` 中，通过 `custom_model_registry` dispatch

这改变了 Qwen3 decode 模式下的算子图:
- 某些 view/permute 操作在新路径中被优化掉了 (op count 63->56)
- 部分之前 HIT 的 shape 现在因新路径产生了不同的中间 shape

### 4.3 MISS 详情 (merge 后新增 / 变化)

| Op | Reason | TC Shape | 说明 |
|----|--------|----------|------|
| `aten.mul.Tensor` | elementwise_output_shape_mismatch | `(1,16,5120)` vs `(1,16,1)` | 新 shape |
| `tensor_cast.rms_norm` | shape_mismatch | `(1,1,5120)` vs CSV `(1,5120)` | batch dim 未 strip (3D) |
| `tensor_cast.apply_rope` | shape_mismatch | `(1,1,16,128)` | 新 shape |
| `tensor_cast.attention` | shape_mismatch | `(16,512)` | decode attention shape |
| `tensor_cast.add_rms_norm2` | shape_mismatch | `(1,1,5120)` vs `(1,5120)` | batch dim (3D) |
| `aten.add.Tensor` | elementwise_output_shape_mismatch | `(1,1,5120)` vs `(1,5120)` | batch dim |
| `tensor_cast.reshape_and_cache` | shape_mismatch | `(16,128)` | 新 shape |
| `aten.index.Tensor` | shape_mismatch | `(40960,256)` | 新 shape |

### 4.4 结论

**这不是 merge bug，而是 develop 架构重构的 side effect。** 接口设计遵从 develop (plugin 架构) 是正确的选择。恢复路径见第八节。

## 五、DSv3 覆盖率分析

### 5.1 DSv3 PF (nq=1, ql=8192) — M3=52.6%, M5=68.9%

| Op (MISS) | Reason | 耗时占比 | 恢复路径 |
|-----------|--------|:-------:|---------|
| `tensor_cast.mlapo_quant` | sub_kernel_miss:QuantBatchMatmulV3 | 高 | MLA composite 子内核 shape 覆盖 |
| `tensor_cast.multihead_latent_attention` | sub_kernel_miss:MatMulV2 | 高 | MLA FIA sub-kernel shape 补采 |
| `tensor_cast.quantize (8192,2304)` | shape_mismatch | 中 | AscendQuantV2 microbench M=8192 |
| `tensor_cast.static_quant_linear (1024,7168)` | shape_mismatch | 中 | MoE expert QuantBMM shape |
| `tensor_cast.swiglu (1024,2048)` | input_count_mismatch | 低 | MoE SwiGlu 路径 tc_input_count 修正 |
| `aten.mul.Tensor (1024,8,7168)` | elementwise_output_shape_mismatch | 低 | elementwise 3D broadcast |

### 5.2 DSv3 DC (nq=5, ql=1) — M3=15.8%, M5=54.3%

DSv3 DC 覆盖率最低，30/87 ops MISS。核心瓶颈:
- MLA composite (mlapo_quant + multihead_latent_attention) shape 全部不匹配
- MoE expert 路径 (static_quant_linear, swiglu, quantize) M=128 (5 tokens/DP) decode shape 无 CSV 覆盖
- Elementwise 3D broadcast 多处不匹配
- DFC 子内核 shape 不匹配 (M=128 MoE expert dim)
