Phase 3 (集成验证) 进行中，交付已延期 4 天。**今日两大突破**: (1) 重新解析全量 profiling 数据 (rank0+rank8, 16 个文件) 带来 shape 覆盖显著提升; (2) 发现 DSv3 缺少 `--enable-shared-expert-tp` 导致 shared expert shape 不匹配，加上后 **DSv3 M3 全部过线 (>50%)**。
